# CineBuzz - Travel at 11:11 Movie & Ticket Booking Portal

CineBuzz is a luxury and interactive web portal intended to present an overview of the upcoming Horror-Comedy movie "Travel at 11:11" and provide an interface for ticket booking.

---

## 🚀 Features

Hero Section & Autoplay Teaser: Animated background video teaser.

About Movie Overview: Movie story summary, and essential details.

Movie Trailer: Interactive player with a custom thumbnail poster.

Meets Characters: Grid view showcasing the 6 main characters and their bio cards.

Movie Recommendation: Interactive movie recommendation block.

Step-by-step Ticket Booking: Simple and intuitive interface to navigate cinema branch, time, and date and payment card selection.

Video Animation Ticket Confirmation: Custom animation video confirmation and display of admit card stamp.

Auto-Page Reload: Session reload logic to ensure fresh booking experience after confirmation.

Fully Responsive: Optimized for Desktop, Tablet, and Mobile devices.

---

## 🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Custom CSS Grid & Flexbox, Glassmorphism design, CSS Animations

Typography: Orbitron & Poppins (Google Fonts)

Assets: Custom MP4 Video clips and PNG character illustrations
